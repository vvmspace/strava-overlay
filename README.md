# Strava Photo Overlay Generator (Vue 3 + Vite) 🏃‍♂️🚴‍♀️

Современное, сверхбыстрое и визуально привлекательное веб-приложение на **Vue 3 (Composition API)** и **Vite** для наложения прозрачного оверлея от Strava (или любого другого скриншота с прозрачным фоном) на ваши фотографии.

Приложение полностью клиентское (вычисления происходят в браузере), благодаря чему оно **абсолютно бесплатно в хостинге**, не имеет лимитов на размер файлов и обрабатывает изображения мгновенно.

---

## ✨ Особенности

* **Архитектура Vue 3:** Использование реактивных переменных (`ref`), наблюдателей (`watch`) и декларативных директив Vue делает код чистым, модульным и поддерживаемым.
* **Сохранение оригинального качества:** Итоговая фотография сохраняется в исходном разрешении и качестве (без сжатия на серверах).
* **Конфиденциальность:** Ваши фотографии не загружаются на сервер. Вся обработка происходит прямо на вашем устройстве с помощью HTML5 Canvas.
* **Тонкая настройка:**
  * 5 пресетов позиционирования оверлея (Сверху-слева, Сверху-справа, По центру, Снизу-слева, Снизу-справа).
  * Интерактивная регулировка размера оверлея (от 10% до 100% от ширины фото).
  * Регулировка отступов от краев фотографии.
  * Регулировка прозрачности оверлея.
* **Современный премиум-дизайн:** Темная спортивная тема в стиле Strava с плавными микро-анимациями и полной адаптивностью.

## 🚀 Как запустить локально

Вам понадобятся установленный **Node.js** (версии 18 и выше) и терминал.

1. **Установка зависимостей:**
   Выполните в папке проекта:
   ```bash
   npm install
   ```

2. **Запуск сервера разработки:**
   Запустите локальный сервер Vite:
   ```bash
   npm run dev
   ```
   После этого перейдите по адресу, который выведется в терминале (обычно `http://localhost:5173`).

3. **Сборка для продакшена:**
   Создание оптимизированного статического бандла:
   ```bash
   npm run build
   ```
   Результат сборки появится в папке `dist/`.

## ☁️ Деплой на Netlify

Благодаря файлу `netlify.toml`, проект готов к автоматическому развертыванию на Netlify:

### Рекомендуемый способ: Через GitHub (Continuous Integration)
1. Создайте новый репозиторий на GitHub и загрузите туда файлы проекта:
   ```bash
   git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   git branch -M main
   git push -u origin main
   ```
2. Авторизуйтесь на [Netlify](https://app.netlify.com/).
3. Нажмите **"Add new site"** -> **"Import an existing project"**.
4. Выберите GitHub, найдите ваш репозиторий.
5. Настройки сборки (`npm run build` в качестве build command и `dist` в качестве publish directory) заполнятся **автоматически** из файла `netlify.toml`.
6. Нажмите **"Deploy"**.
7. Теперь при каждом `git push` ваш сайт будет автоматически обновляться на Netlify!
